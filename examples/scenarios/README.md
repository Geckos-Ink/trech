# Scenarios

Each folder contains `<name>.js` (physics), `<name>.view.js` (presentation),
`<name>.validation.js` (expectations) and `<name>.ui.js` (typed controls/documentation).
Run the physics entry point; companions load automatically in CLI, library and Studio use.

See [the bundle contract](../../docs/scenario_bundles.md) for authoring and validation commands.
Reusable TRECH JavaScript modules live in [`js/`](../../js/), and data/models in [`data/`](../../data/).
